# Coordinate

**Source:** [[Coordinate.java](../../src/main/java/com/ple/visur/Coordinate.java)]
**Date updated:** 2026-10-13

## Summary

The Coordinate class represents an immutable (x, y) position on the editor canvas.[^1] Used for cursor positioning and viewport calculations. The coordinate system uses character-cell-based coordinates (not pixel coordinates).

## Key Takeaways

- Immutable (x, y) position representation
- Used for cursor positioning on the canvas
