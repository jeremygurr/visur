Cursor Coordinates Map

One persisted fact (ca) · two mutually exclusive views (caAndNL ↔ cxcyAndNL) · three coordinate spaces · companion to Lesson 8

The cursor is stored once and displayed in several coordinate systems. The persistent truth is ca, the absolute character index. Logical line/column (cx, cy) is derived from ca and the shared read-only nl list, and the viewport is a third, purely visual space on top. This page is the compressed map.

nl is next-line indices: nl[k] is where logical line k+1 starts. Its final element is the content length, not a newline position. So [12, 25, 32] is three lines starting at 0, 12, and 25, with the document ending at 32.

Gotchas

  • ca is the only persisted truth. cx/cy exist only while some caller reads them.
  • Derivation bypasses conflict removal. cacheVal is not put, so the "only one decomposition" rule is not re-enforced on reads.
  • calcCXCYAndNL caches both cx and cy even when asked for just one.
  • The reverse scan is strict: nl[cy] > ca. At ca == nl[k] the cursor belongs to line k+1, cx = 0.
  • nl's last element is the content length, so the final line has no following newline index.
  • Primitive cx/cy are non-negative: WholeNumberDC.isValidInput rejects negative integers.
  • Setting cx/cy unsets ca (and vice versa) through Catalyst Permanence — see the Data Class Map.
