Gotchas

  • Routing is by submode, not mode. keymapMap is a Map<EditorSubmode, Keymap>, and KeyWasPressedVerticle looks up the current submode.
  • putEditorSubmode pushes. The name says "put"; the body pushes onto the stack.
  • "navigate" means reset. Pushing it pops the stack down to one entry, which is why Escape is one word.
  • changeMode writes twice: it peeks to set the mode, then PushSubmodeOp pops the same string as a submode name.
  • changeMode "replace" leaves the mode unchanged because replace is not an EditorMode. Only the submode changes.
  • EditingModeHandler is dead. It is never placed on any keymap; the navigate fallback is ChangeCursorQuantumHandler.
  • ModeSwitchService is dead. Its execute body is commented out.
  • Handlers are fallbacks. Keymap.get tries explicit bindings first, then each handler until one returns non-null.
